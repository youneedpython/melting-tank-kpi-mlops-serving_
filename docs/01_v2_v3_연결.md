# v2와 v3의 연결

v2는 Notebook에서 검증한 학습 절차를 Python/MLflow 파이프라인으로 재현합니다. v3는 재학습하지 않고 v2가 생성한 모델 번들을 로드하여 API 추론을 제공합니다.

| 단계 | 저장소 | 책임 |
|---|---|---|
| v1 | modeling | Notebook 기반 탐색·모델링·평가 |
| v2 | modeling | 재현 가능한 Python 학습·MLflow 추적·KPI 판정 |
| v3 | serving | 승인 모델 로드·FastAPI 추론·운영 데이터 저장·Docker 실행 |

## 모델 번들 계약

v3의 `artifacts/`에는 v2 Run의 `model_bundle`에서 내려받은 다음 파일이 필요합니다.

- `model.keras`
- `scaler.joblib`
- `model_config.json`
- `metrics.json`

`model_config.json`의 특성 순서·시퀀스 길이·타깃 규칙·임계값은 학습 시점과 동일해야 합니다. `metrics.json`의 `deployment_approved`가 `true`인 모델만 기본 설정에서 추론할 수 있습니다.
