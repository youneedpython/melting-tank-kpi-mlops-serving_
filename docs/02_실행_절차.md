# v3 실행 절차

## 로컬 실행

```bash
conda activate <v2에서 사용한 환경>
python -m pip install -e ".[dev]"
python -m pytest
python -m uvicorn app.main:app --reload
```

확인 주소는 `/healthz`, `/readyz`, `/status`, `/docs`, `/dashboard`입니다.

현재 v2 baseline처럼 KPI 미승인 번들을 수업 목적으로만 실행하려면 별도 터미널에서 환경변수를 지정합니다.

```bash
# Windows PowerShell
$env:ALLOW_UNAPPROVED_MODEL="true"
python -m uvicorn app.main:app --reload
```

## Docker 실행

```bash
docker compose up --build -d
docker compose ps
docker compose logs -f api
```

미승인 번들의 개발 확인은 `.env`에 `ALLOW_UNAPPROVED_MODEL=true`를 설정한 경우에만 가능합니다. 실제 배포에서는 이 값을 사용하지 않습니다.
